# farid1292

## Description
Ce projet Python inclut une fonctionnalité de lecture de documents PDF.

## Fonctionnalités
- Lecture de documents PDF
- Extraction de texte de toutes les pages d'un PDF
- Support des fichiers PDF multi-pages

## Installation
```bash
pip install -r requirements.txt
```

## Utilisation
```python
from fardigit import lire_pdf

# Lire un fichier PDF
contenu = lire_pdf('chemin/vers/fichier.pdf')
print(contenu)
```

Ou exécutez directement le script:
```bash
python fardigit.py
```

## Réponse à la question
**Oui, je peux lire un document PDF!** Utilisez la fonction `lire_pdf()` pour extraire le texte d'un fichier PDF.
